**New: put the shader gradient on your own website as a live, animated background.**

- In the export dialog you now find a Web Component, a React component and an HTML embed. Paste the code and the gradient runs in the visitor's browser, exactly like in the editor.
- The player weighs under 3 KB, needs no library and loads nothing from Musterli. It pauses off screen and in hidden tabs and stands still for visitors who prefer reduced motion.
- Developers also get the raw GLSL shader with all values of their design.
