**Neu: drei Code-Werkzeuge für Webdesign.**

- Easing-Kurven gestaltet Zeitfunktionen als `cubic-bezier()` oder als Feder mit `linear()`. Ein Punkt zeigt die Bewegung, der Code kommt als Transition, Animation und Tailwind-Theme.
- Die fliessende Abstandsskala rechnet Abstände von 3xs bis 3xl, die zwischen zwei Bildschirmbreiten mitwachsen, als CSS-Variablen mit `clamp()`, Hilfsklassen oder Tailwind-Theme. Paare wie s-l machen grosse Sprünge.
- Verlaufstext füllt Überschriften mit einem Farbverlauf, auf Wunsch mit wanderndem Glanz. Du erhältst CSS mit `background-clip: text` und Tailwind-Klassen.
