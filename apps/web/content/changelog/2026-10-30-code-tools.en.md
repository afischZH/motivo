**New: three code tools for web design.**

- The CSS easing generator shapes timing functions as `cubic-bezier()` or as a spring with `linear()`. A dot shows the motion, and the code comes as a transition, an animation and a Tailwind theme.
- The fluid spacing scale computes spaces from 3xs to 3xl that grow between two viewport widths, as CSS variables with `clamp()`, utility classes or a Tailwind theme. Pairs like s-l make bigger jumps.
- Gradient text fills headlines with a gradient, with an optional sliding shine. You get CSS with `background-clip: text` and Tailwind classes.
