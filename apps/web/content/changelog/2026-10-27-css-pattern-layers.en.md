**New: CSS patterns with layers.**

- Stack up to five patterns over a background color. Each layer has its own pattern, colors, size, angle and opacity.
- Add, duplicate, reorder, show, hide or remove layers with buttons or the keyboard (arrow keys select, Alt plus arrow moves, Delete removes).
- Pick the pattern from a grid of small thumbnails.
- Space re-rolls all layers. Lock single values of a layer, or lock "Layers" to keep the whole stack.
- All seven presets now stack several layers, such as Picnic, Highland and Night Dots.
- CSS, Tailwind, SVG and image exports contain all visible layers. Shared links from the pattern library keep working.
